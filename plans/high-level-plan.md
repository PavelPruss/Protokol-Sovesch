# Верхнеуровневый план реализации

## Этап 1. База проекта
- Зафиксировать требования в `agents.md`.
- Определить формат входа/выхода для MVP.
- Подготовить `.env`-подход для ключей OpenRouter.

## Этап 2. Прием и подготовка файлов
- Реализовать загрузку файлов встречи через веб-интерфейс.
- Проверять типы, размер и целостность файлов.
- Приводить файлы к удобному формату для обработки.

## Этап 3. Транскрибация
- Подключить транскрибацию через OpenRouter/подходящую модель.
- Разбивать длинные записи на части для устойчивой обработки.
- Склеивать части в единый `transcript.txt`.

## Этап 4. Анализ содержания встречи
- Выделять из транскрипта решения, поручения, сроки и ответственных.
- Отмечать неясные места (если срок/ответственный не найден).
- Собирать структурированный `action_items.json`.

## Этап 5. Генерация протокола
- Собирать `protocol_draft.md` по утвержденному шаблону.
- Добавить обязательные разделы: повестка, решения, задачи, риски, следующие шаги.
- Подготовить удобный просмотр и скачивание результата.

## Этап 6. Качество и стоимость
- Добавить логи по шагам: время, ошибки, стоимость токенов.
- Настроить ограничения на объем контекста для экономии.
- Проверить точность на 3-5 реальных встречах.

## Этап 7. Запуск в работу
- Сделать простую инструкцию использования для команды.
- Утвердить критерии "готово к использованию".
- Перевести решение в регулярную эксплуатацию.

## Итоговый результат
Рабочий веб-инструмент, куда загружаются файлы Zoom-встречи, а на выходе автоматически получаются:
- расшифровка встречи,
- структурированный список поручений,
- черновик протокола совещания.
